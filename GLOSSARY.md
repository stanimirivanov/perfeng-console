# Console language

Terms for the operator Run journey and independent platform verification. Shared terms are defined in the [Perfeng glossary](https://github.com/stanimirivanov/perfeng-contracts/blob/main/GLOSSARY.md).

## Language

**Run Detail**
The operator view of a Run’s lifecycle, source identities and authorized evidence.

**Scenario Lab**
The maintainer area for independent verification using predefined scenarios and separately authorized execution.

**Expectation Manifest**
Versioned scenario inputs, expectations and tolerances frozen before execution and bound to approval by digest.

**Campaign**
A verification exercise using a frozen set of expectations and declared repetitions.

**Tier A Evidence**
Synthetic evidence used to exercise Console and verification behavior.

**Tier B Evidence**
Observations from separately approved live platform Runs.

**Finding**
A mismatch between an independently approved expectation and an observation.

**Current-Phase Obligation**
An expectation the platform is required to satisfy in the current delivery phase.

**Research Target**
A separately reported verification objective beyond current-phase obligations.
