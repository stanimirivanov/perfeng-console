# Simulator execution

Own durable step identity, active-time accounting, public API submissions and the fixed environment adapter. Separate ground truth about a perturbation from public evidence of a platform outcome. Require a fresh approval for each mutation and reconcile uncertain dispatch before retry.

Read the [layer matrix](../../HARNESS.md) and run `make architecture` after changing dependencies.

The [runtime ownership model](../../docs/development/runtime-ownership.md) preserves
this process boundary. Console Effect adoption does not admit runner dependencies or
move approvals into UI state. Keep independent verifier release/acceptance gates;
interruption after dispatch requires reconciliation, not an automatic retry.
